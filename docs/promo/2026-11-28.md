**Title:** Mihomet v1.3.8 — more reliable Xray/Happ imports for Android mihomo

**Post:**

Mihomet v1.3.8 is now published: an open-source Android client for the mihomo core
(GPL-3.0), with non-root VPN mode and a root TProxy mode.

This release focuses on imports that are difficult to diagnose when a converter silently
drops data:

- Reworked Xray JSON/JSONC and Happ-array conversion with scoped references, server/user
  expansion, validated dependencies, deduplication and native logical routing rules.
- Compatible transports and XHTTP options are preserved where the pinned core supports them;
  unsupported settings are reported. VLESS KCP and additional Reality verification cases are
  rejected explicitly instead of being presented as successful conversions.
- Conversion reports are saved with profiles and include skipped nodes/rules and credential-free
  schema paths.
- Subscription response selection validates each response and prefers a richer, less lossy
  response while keeping its title, quota and update interval together.
- URL, clipboard, file and external-link imports use the same validated, atomic profile flow.
- Reality interoperability was restored for the tested current and older Xray cases without
  changing the pinned Mihomo core.

Pre-release verification completed 664 JVM tests, 25 mandatory device tests on each of Android
API 26 and API 35, and 16 local wire cases against Xray 26.10.31 and 25.3.6 on both emulator
versions. Device checks used app 1.3.7 (13) before the v1.3.8 version bump; R8 smoke used a
locally debug-signed APK copy. No public proxies were contacted. Checks also covered imports,
subscription refreshes, persisted conversion reports, native VPN start/stop and light, dark and
AMOLED rendering. See the [verification report](https://github.com/mihomet/mihomet/blob/v1.3.8/docs/verification-2026-11-27.md).

Please read the limits before testing: the device checks used x86_64 emulators. Physical ARM
devices and root/TProxy hardware were not verified in this pass, and the tests do not establish
universal cross-core compatibility.

The codebase is entirely AI-generated, and there has been no independent security audit. Read
the tagged [Trust & threat model](https://github.com/mihomet/mihomet/blob/v1.3.8/README.md#trust--threat-model-read-before-installing).
Treat this as a project that needs review, issue reports and converter/firewall scrutiny, rather
than as an audited security product.
